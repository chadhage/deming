# Competency Taxonomy

Source: `docs/Certification-Poster_en-us.pdf` (Microsoft + GitHub Credentials poster, last updated June 2026).
This file is the machine- and human-readable extraction of the poster tiles referenced by
`docs/contracts.md` §2.2 and §2.3. Agents derive their expertise scope from this taxonomy.

Competency depth per agent:

- **ci-csa-agent** — L400 (expert) across **Cloud & AI Platforms**, **Security**, **Modern Work**,
  and **AI Business Solutions (Dynamics 365 + Power Platform)**.
- **ci-csam-agent** — Microsoft **Fundamentals**-level competency across the same tiles, plus basic GAAP.
- **deming** — does not own cert competencies; it coaches CI/quality across both agents.

## Certification types

| Type | Intent |
| --- | --- |
| Fundamentals | Master the basics |
| Role-based | Expand your technical skill set |
| Specialty | Deepen skills and manage industry solutions |
| Business | Expand AI skills for business roles |
