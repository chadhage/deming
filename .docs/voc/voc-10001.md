# Capture tasks before I forget them

## Voice of the customer

"I need a fast, simple way to record what I have to do as soon as I think of it, so nothing important slips through the cracks."

## User Story

As a busy person, I want to add a task with only the details I know, so that I can capture it now and organize it later.

## Acceptance criteria

- I can create a task by entering a title.
- I can optionally add notes, a due date, and a priority.
- My new task is saved and appears in my task list immediately.
- If a task cannot be saved, I am clearly told what went wrong and my entered details are preserved.

## Confirmations

- A task can be captured in a few seconds without completing optional fields.
- The saved task remains available after I close and reopen the app.
