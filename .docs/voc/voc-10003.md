# Finish tasks and keep my list current

## Voice of the customer

"I want an easy way to mark work as done and clean up plans that changed, while still being able to recover from a mistake."

## User Story

As a to-do app user, I want to complete, edit, and remove tasks, so that my list accurately reflects what I still need to do.

## Acceptance criteria

- I can mark an active task as complete and clearly see its completed state.
- I can edit a task without creating a duplicate.
- I can remove a task I no longer need.
- I can undo an accidental completion or deletion.
- Completing or removing one task does not change any other task.

## Confirmations

- Completed tasks no longer distract from active work but can still be reviewed.
- Changes remain accurate after I close and reopen the app.
